Optional detailed map
---------------------
Put a Natural Earth "ne_110m_admin_0_countries" (or 50m) GeoJSON here named world.geojson, or in
<user data folder>/maps/world.geojson (Settings > Map data > Open maps folder). Restart the game.
Features are matched to the game's nations by ISO_A3 / ADM0_A3. Unmatched countries become neutral land.
